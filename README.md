# Block Clock

時間を「10単位の大きなブロック」と「1単位の小さなブロック」で表現する時計です。

## Web版

- `index.html`: ブロック時計
- `Large_clock.html`: 大きなデジタル時計

ブラウザでHTMLファイルを開くと動作します。

## macOSアプリ版

`macOS` フォルダには、Xcodeを使わずにビルドできるメニューバー常駐版があります。

主な機能:

- 時・分・秒を3本のブロック塔で表示
- 数字表示のオン／オフ
- 小・中・大の表示サイズ
- 最前面表示の切り替え
- バックグラウンド時のウィジェット風透過
- 表示位置と設定の保存

### ビルド

```sh
cd macOS
./build.sh
```

完成したアプリは `macOS/dist/Block Clock.app` に作成されます。
